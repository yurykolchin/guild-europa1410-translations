# Pacote adicional para a tradução portuguesa

Para **The Guild 1 Remake: Europa 1410**, versão **0.5.3.27207**. Requer o mod do Steam Workshop [Tradução portuguesa 0.1.0](https://steamcommunity.com/sharedfiles/filedetails/?id=3843100449).

O pacote acrescenta textos da interface, nomes dos bairros e legendas dos diálogos e do narrador. As vozes mantêm-se no idioma original.

[Descarregar o ZIP](https://github.com/yurykolchin/guild-europa1410-translations/releases/download/pt-PT-v0.1.0/Guild1-Portuguese-Extra.zip) · [Descarregar os ficheiros em separado](package/)

Fecha o jogo e abre a pasta de instalação através do Steam. Extrai os três ficheiros do ZIP para `Europa1410/Content/Paks/~mods`. Se a pasta `~mods` não existir, cria-a. Depois, inicia o jogo e seleciona o português nas definições.

# Pacote adicional para a tradução brasileira

Para **The Guild 1 Remake: Europa 1410**, versão **0.5.3.27207**. Requer o mod [Tradução brasileira 0.1.0](https://steamcommunity.com/sharedfiles/filedetails/?id=3843136239) do Steam Workshop.

O pacote acrescenta textos da interface, nomes dos bairros e legendas dos diálogos e do narrador. As vozes continuam no idioma original.

[Baixar o ZIP](https://github.com/yurykolchin/guild-europa1410-translations/releases/download/pt-BR-v0.1.0/Guild1-BrazilianPortuguese-Extra.zip) · [Baixar os arquivos separadamente](package/)

Feche o jogo e abra a pasta de instalação pelo Steam. Copie os três arquivos do ZIP para `Europa1410/Content/Paks/~mods`. Se a pasta `~mods` não existir, crie-a. Abra o jogo e selecione português (Brasil) nas configurações.

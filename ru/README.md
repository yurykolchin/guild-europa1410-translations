# Дополнение к русскому переводу

Для игры **0.5.3.27207**. Требуется мод из Steam Workshop [Русская локализация 1.2.3](https://steamcommunity.com/sharedfiles/filedetails/?id=3832058792).

Дополнительные надписи интерфейса, названия кварталов и субтитры.

[Скачать ZIP](https://github.com/yurykolchin/guild-europa1410-translations/releases/download/ru-v1.2.3/Guild1-Russian-Extra-2026-11-20.zip) · [Скачать отдельные файлы](package/)

Закройте игру и распакуйте три файла из ZIP в `Europa1410/Content/Paks/~mods`. Если папки `~mods` нет, создайте её. Запустите игру и выберите русский язык.
